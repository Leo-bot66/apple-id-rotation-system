# Security Policy

## Supported versions

Security fixes are applied to the latest revision on the default branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. If that option is unavailable, open a public issue containing only a request for a private contact channel.

Do not include credentials, TOTP seeds, mailbox contents, personal data, server addresses, exploit details, or other sensitive material in a public issue.

We aim to acknowledge a report within seven days. Timelines for validation and remediation depend on severity and reproducibility.

## Scope

The repository intentionally excludes service-specific login automation, CAPTCHA bypass, verification-code forwarding, and production infrastructure configuration. Reports about bypassing those boundaries are welcome when they concern code present in this repository.
